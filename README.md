# Package: Vibe Coding and Technical Debt

This repository contains the package for the master thesis:

**Vibe Coding and Technical Debt: A Multivocal Literature Review and Mixed-Methods Study**

Authors:

- Victor Mertala
- Vasilije Ivanisevic

Mälardalen University  
School of Innovation, Design and Engineering  
Master of Science in Computer Science with Specialization in Software Engineering

---

## Repository Contents

This repository includes the supplementary material used in the thesis.

### `data/survey/`

Contains the anonymized survey answers collected during the empirical part of the study.

File:

- `survey_answers.xlsx`

### `data/interviews/`

Contains anonymized interview transcripts from the follow-up interview sessions conducted after the survey.

Files:

- `Interview session 1.docx`
- `Interview session 2.docx`
- `Interview session 3.docx`

### `data/slr/`

Contains the Excel file used for the literature review data extraction and analysis.

File:

- `slr_data_extraction.xlsx`

---

## Data Anonymization

All empirical data included in this repository has been anonymized.

No personally identifiable information is included in the survey answers or interview transcripts. Any names, email addresses, company names, or other identifying details were removed or generalized before publication.
